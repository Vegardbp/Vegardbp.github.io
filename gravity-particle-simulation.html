GPU Particle Simulation

TypeScript · React · Babylon.js · WebGPU · WGSL

A real-time N-body particle simulation running entirely on the GPU using WebGPU compute shaders.

Each particle calculates its gravitational interaction with every other particle in parallel, with particle positions and velocities kept in GPU storage buffers throughout the simulation.

The simulation includes interactive controls for gravity strength, particle count, starting velocity, and starting radius. The rendering is also performed on the GPU using a storage texture and custom WGSL shaders.

Interactive real-time simulation

Details

GPU N-body simulation Every particle calculates the gravitational force from every other particle using a compute shader, giving the simulation an O(n²) computational workload
Compute shaders Simulation logic is written in WGSL and executed through WebGPU compute shaders, with 256 GPU threads processed per workgroup
GPU particle storage Particle positions and velocities are stored in GPU storage buffers and updated directly by the compute shader, avoiding CPU readback every frame
Custom rendering Particles are rendered directly into a GPU storage texture using a Gaussian falloff, then displayed through a post-process pass
Interactive simulation Gravity strength, particle count, starting velocity, and starting radius can all be changed through the interface and applied to a new simulation
Performance testing The simulation includes a live FPS counter and supports up to 32,768 particles, making the computational cost of the N-body approach directly observable
