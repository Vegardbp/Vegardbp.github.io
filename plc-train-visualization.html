PLC Train Visualization

Unity · C# · Modbus TCP · CODESYS · Blender

3D visualization for an automated model railway, connected directly to a PLC over Modbus TCP.

I was primarily responsible for the Unity simulation, the communication between Unity and the PLC, and integrating the controls from the visualization into the PLC program.

The visualization receives the current and next sensor position for each train, interpolates the train movement between them, and allows the operator to select a train and send it to a chosen station.

Details

Modbus TCP communication Unity receives train position data from the PLC and sends target positions back for manual control
Sensor-based interpolation The PLC sends the previous and expected next sensor, while Unity interpolates the train's position between them
Interactive train control The user can select a train and choose a target station directly in the 3D visualization
PLC integration Unity commands are fed into the same manual-control logic used by the PLC program
3D environment Railway, terrain and other assets were built for the visualization, with the track based on the physical model
Performance fallback Manual GPU instancing is used for the grass, with a Simple Visuals mode that disables expensive scenery
